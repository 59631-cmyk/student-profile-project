# Student Profile Project

## Project Description
This project is a simple student profile system that displays basic student information.

## Features
- Displays student name and ID.
- Shows department and semester.
- Provides a simple and clear profile layout.

## Technologies Used
- HTML
- CSS
- GitHub for version control and collaboration.

## Purpose
The purpose of this project is to demonstrate GitHub branching, commits, pull requests, code review, and merging.
